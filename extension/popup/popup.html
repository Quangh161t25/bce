Cau hinh Gemini

API Key va model duoc luu trong trinh duyet nay bang chrome.storage.local.

Chức năng API Gemini:

Trong extension của bạn, Gemini API đang được dùng để tự động viết mô tả sản phẩm chuẩn SEO bằng AI.
Cụ thể, khi extension xử lý chức năng "Tạo mô tả bằng AI", nó sẽ gửi tên sản phẩm của bạn cho Gemini cùng với lệnh:
"Hãy đóng vai chuyên gia viết nội dung chuẩn SEO cho các sàn thương mại điện tử..."
Yêu cầu viết đoạn mô tả hấp dẫn, bao gồm: Lời giới thiệu thu hút, Tính năng nổi bật, và Lợi ích khi sử dụng.
Kết quả trả về sẽ tự động định dạng bằng HTML cơ bản (<p>, <b>, <ul>, <li>...) để hiển thị đẹp mắt và chuẩn form khi dán lên Shopee.

⚡ API Dự phòng (XKiro AI: DeepSeek, Qwen Free...) Tự động chạy khi Gemini hết hạn / quá tải
