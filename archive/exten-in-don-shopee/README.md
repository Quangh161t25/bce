# Shopee Seller Helper

Extension da duoc rut gon con luong in don.

## Chuc nang con lai

- Mo quy trinh in don Shopee.
- Chon hop kiem, kho xu ly va dia chi lay hang.
- Yeu cau van chuyen toi lay hang.
- Tao phieu PDF va xuat don cho lay hang.
- Chon thu muc may tinh de xem nhanh file PDF/Excel hom nay.

## File chinh

- `print-panel.html`: giao dien side panel.
- `print-panel.css`: giao dien luong in don.
- `print-panel.js`: logic side panel.
- `seller-flow.js`: content script thao tac tren Shopee.
- `core-worker.js`: service worker tai PDF va mo side panel.
